How to use this file (read before generating anything)

This file is the source of truth

Use only the tokens and components defined here. Do not invent colors, fonts, sizes, or spacing. If something isn't covered, pick the closest defined token - never improvise.

No eyebrow / kicker text

Never place a small uppercase label above a heading. Headings stand on their own.

No one-sided accent cards

Cards use full, even 1px borders. Never a thick stroke on one side (no border-left:3px).

No gradients · Phosphor only

Flat fills only in decks - no gradients. All icons are Phosphor; Lucide and other sets are banned.

Logo usage

The Guild logomark is a reversed (white) mark made for dark backgrounds - it is invisible on white. Always place it on a dark container (the brand uses #101010), as shown below. Give it clear space equal to its icon height, and keep it legible (min ~24px tall).

Do
  • Reversed mark - use on dark only (e.g. #101010 chip or panel).
  • Keep generous clear space around it.
  • Scale proportionally.
Don't
  • Place the white mark on white or light photographic backgrounds - it disappears.
  • Recolor, stretch, or add effects to the mark.
  • Crowd it against text or slide edges.

Layout & motion

Presentations use a 16:9 canvas (1280x720) with a consistent inner safe margin. This doc site uses a 150px page margin so content sits centered and unhurried - mirror that generosity in decks. Motion is quiet (and there are no hover colour effects): 0.15s state changes, 0.25s transitions, up to 0.4s reveals; easing cubic-bezier(.4,0,.2,1). No bounces or spins.

16:9 slide · ~7% safe margin

Motion

Motion is a foundational element of this system, not decoration. It is quiet and purposeful: it guides the eye on slide changes, confirms interaction, and lets data arrive instead of appearing. Every duration and curve below is a token - reuse them so a whole deck moves with one rhythm. Honour prefers-reduced-motion everywhere (this page does).

--dur-fast0.15sHovers, button & link state, taps
--dur0.25sDefault transitions, accordions, toggles
--dur-slow0.4sReveals, slide changes, larger moves
--easecubic-bezier(.4,0,.2,1)One easing curve for everything - decelerate to rest

Patterns - hover any tile; press Replay to re-run the entrance set

Do
  • Reuse the three duration tokens and the single easing curve.
  • Animate in - reveal, count, draw, fill - so data feels earned.
  • Stagger groups by ~60-90ms; keep total entrances under ~0.6s.
  • Always provide a reduced-motion fallback.
Don't
  • No bounces, spins, elastic, or parallax.
  • No looping/auto-playing motion that pulls focus from content.
  • Don't animate more than two properties at once (opacity + transform).
  • Never block reading - motion finishes fast, then gets out of the way.

Buttons

Buttons mark the single most important action on a slide (a CTA) or navigation in an interactive deck. Use sparingly.

When to use
  • Primary call-to-action ("Shop Carts").
  • Navigation controls in an interactive deck.
When not to use
  • As a label or badge - use a Tag.
  • More than one primary button per view.
Guild uses four button types - primary (blue), secondary (stroke: transparent with the brand stroke --ggc-border), sticky (dark fill, reserved for the sticky bottom bar) and text (link-style). All are fully pill-shaped and the filled ones carry the brand's signature inner top-light shadow (0 1px 3.3px rgba(255,255,255,.45) inset).

Primary - blue CTA (one per view)

Secondary - stroke (pair with a primary)

Sticky - dark fill (sticky bottom bar only)

Text - link-style, no fill

Charts

Chart.js, brand palette, flat fills - for data slides and reports.

Chart palette & principles

Lead a chart with one blue series; use neutral darks for supporting series so the brand color signals the data that matters. Reserve green/red for status only.

Primary series · #3871b0 Primary light · #bcd2ea Neutral series · #2d333e Neutral light · #9bb4d4 Success Danger
Do
  • Use one blue series as the focus; neutrals for the rest.
  • Label axes lightly; keep gridlines the border color.
  • Round bar corners 4px to match the brand.
Don't
  • Use gradient fills or 3-D effects.
  • Color every series differently - it reads as noise.
  • Use green/red unless it means good/bad.

JS
new Chart(el, {
  type:'line',
  data:{ labels: dates, datasets:[
    { label:'Clicks', data: clicks, yAxisID:'y',
      borderColor:'#3871b0', borderWidth:2.5, tension:0, pointRadius:0, pointHoverRadius:4 },
    { label:'Impressions', data: impressions, yAxisID:'y1',
      borderColor:'#2d333e', borderWidth:2, tension:0, pointRadius:0, pointHoverRadius:4 } ] },
  options:{ maintainAspectRatio:false, interaction:{mode:'index',intersect:false},
    plugins:{ legend:{display:false},
      tooltip:{ backgroundColor:'#333333', borderColor:'#333', borderWidth:1, padding:12,
        callbacks:{ label:function(c){ var v=c.parsed.y;
          return c.dataset.label==='Impressions'
            ? ' Impressions: '+(v>=1000?(v/1000).toFixed(1)+'K':v)
            : ' Clicks: '+v; } } } },
    scales:{
      x:{ grid:{display:false}, border:{color:'#e6e6e6'} },
      y:{  position:'left',  title:{display:true,text:'Clicks'},
           grid:{color:'#e6e6e6'}, border:{display:false} },
      y1:{ position:'right', title:{display:true,text:'Impressions'},
           grid:{drawOnChartArea:false}, border:{display:false},
           ticks:{ callback:function(v){ return v>=1000 ? (v/1000)+'K' : v; } } } } }
});
Do
  • Put the focus metric (Clicks) in blue on the left axis.
  • Label both axes and keep gridlines on the left axis only.
  • Back it with a KPI row of the period totals.
Don't
  • Use two saturated colors - keep Impressions neutral slate.
  • Draw both axis grids; the second set adds clutter.
  • Add gradient fills under the lines.
